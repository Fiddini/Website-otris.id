STEP 1: Install Open Source Base

# di server OTRIS.ID
git clone https://github.com/ikhsan3adi/absensi-sekolah-qr-code.git otris-absensi
cd otris-absensi
composer install
cp env .env
# setting database di .env -> DB baru: otris_absensi

STEP 2: Kunci Mati - Ganti Jadi API Key Baru

STEP 3: Sambung ke Directus 06 Media (PENTING)

Tambah file ini: app/Libraries/OtrisBridge.php

<?php
// Kirim setiap absen ke Directus yang sudah READY
function kirimKeOtris($data) {
  $directus_url = "https://otris.id/items/06_media";
  $token = "TOKEN_DIRECTUS_KUNCI_MATI";
  
  $payload = [
    "identitas" => $data['nis'],
    "sekolah" => $data['sekolah'],
    "jam_hadir" => date('Y-m-d H:i:s'),
    "foto_doc_cam" => $data['foto'],
    "status" => "hadir",
    "kode_dokumen" => "ABSEN-SEGITIGA-".time()
  ];
  
  // cURL ke Directus
  $ch = curl_init($directus_url);
  curl_setopt($ch, CURLOPT_POSTFIELDS, json_encode($payload));
  curl_setopt($ch, CURLOPT_HTTPHEADER, [
    'Content-Type: application/json',
    'Authorization: Bearer '.$token
  ]);
  curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);
  return curl_exec($ch);
}

Dengan ini, SEMUA absen masuk ke 06 Media yang kuncinya cuma ang pegang.

STEP 4: Flow Directus -> WA Ortu (Segitiga)

Di Directus > Flows > Buat Flow Baru:

  • Trigger: Item Created di 06_media
  • Action 1: Read Item -> ambil no HP ortu dari tabel siswa
  • Action 2: Send Webhook -> ke WA Gateway baru
Pesan WA:
