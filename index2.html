Banyak rumah sakit memiliki fasilitas,
namun tidak memiliki akses ke dokter subspesialis.

  • Pasien harus dirujuk ke rumah sakit lain
  • Terjadi keterlambatan penanganan
  • Risiko pasien meningkat
  • Biaya operasional membengkak

Masalah utama bukan alat.
Masalah utama adalah akses ke keahlian.

SOLUSI: OTRIS

OTRIS adalah sistem orkestrasi ruang operasi
yang menghubungkan dokter, data pasien,
dan perangkat medis dalam satu sistem real-time.

Dengan OTRIS:
Dokter spesialis dapat melihat, menganalisis,
dan memberikan arahan secara langsung
tanpa harus berada di lokasi.

Yang berpindah bukan pasien,
melainkan data dan keahlian.

BUKAN SEBUAH PERANGKAT

BUKAN TELEMEDICINE
BUKAN VIDEO CALL

INI ADALAH SISTEM

OTRIS adalah:
• Sistem integrasi perangkat medis
• Platform kontrol dan monitoring
• Infrastruktur kolaborasi dokter real-time

OTRIS bukan produk.
OTRIS adalah infrastruktur layanan medis modern.

CARA KERJA OTRIS

  1. Data pasien ditangkap dari perangkat medis
  2. Data dikirim ke sistem OTRIS secara real-time
  3. Dokter spesialis mengakses dari lokasi berbeda
  4. Analisis dilakukan langsung
  5. Instruksi diberikan ke tim medis
  6. Tindakan dilakukan tanpa rujukan

Semua proses terjadi dalam satu sistem terintegrasi.

SISTEM OTRIS

OTRIS mengintegrasikan:

  • Visual tindakan (multi-camera)
  • Data medis pasien
  • Komunikasi dokter
  • Dashboard monitoring
  • Sistem kontrol perangkat (tablet)
  • Integrasi SATUSEHAT (FHIR / HL7)

Arsitektur:
Device → Gateway → Core System → Cloud

Dirancang untuk:
Real-time, Low latency, Multi-device, Multi-hospital

IMPLEMENTASI SISTEM

OTRIS bukan pengadaan alat.
Melainkan proses:

Pengadaan → Instalasi → Integrasi → Testing → Operasional

  • Pekerjaan sipil ruang operasi
  • Instalasi & wiring
  • Integrasi sistem
  • Penyesuaian teknis
  • Commissioning & testing

Sistem baru berjalan setelah semua terintegrasi.

DAMPAK IMPLEMENTASI

Bagi Rumah Sakit:

  • Mengurangi rujukan pasien
  • Meningkatkan kapasitas layanan
  • Efisiensi operasional
  • Meningkatkan pendapatan layanan

Bagi Pasien:

  • Penanganan lebih cepat
  • Tidak perlu pindah rumah sakit
  • Biaya lebih efisien

Bagi Sistem:

  • Pemerataan layanan medis
  • Penguatan sistem rujukan nasional

MODEL KERJASAMA (KSO)
