# Website OTRIS.id

Ini adalah repositori resmi untuk pengembangan platform **OTRIS (Operating Theatre Referral Integrated System)**.

## Tentang Proyek
OTRIS adalah sistem integrasi yang dirancang untuk mempermudah rujukan dan koordinasi di ruang operasi rumah sakit secara digital dan real-time.

## Fitur Utama
- Manajemen rujukan antar rumah sakit.
- Monitoring ketersediaan fasilitas medis.
- Integrasi sistem informasi kesehatan.

## Pengembangan
Proyek ini dikembangkan menggunakan teknologi web standar untuk memastikan kecepatan dan kemudahan akses.
